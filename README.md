# Temperatura Mascotas

## dispositivos lowtech e interfaces interactivas 

**Equipo:** Los Firulais  
**Problematica:** Temperatura ambiental y bienestar de mascotas  

![Foto del equipo](imagenes/S01/foto-equipo.jpg)

## Descripción

Dispositivo Low Tech que mide la temperatura del ambiente para ayudar a los dueños de mascotas a identificar cuándo las condiciones pueden ser incómodas para sus perros, permitiendo tomar acciones como abrigarlos o cambiar su ubicación.

## Desafío o problematica  inicial

Los dueños de perros no siempre pueden identificar si la temperatura del lugar donde se encuentra su mascota es adecuada. El desafío es hacer visible esta condición mediante un dispositivo que mida la temperatura ambiental y entregue una alerta fácil de interpretar.

## Objetivo 

Diseñar un dispositivo Low Tech capaz de medir la temperatura ambiental y comunicar de manera simple cuándo una mascota podría necesitar mayor protección frente al frío o calor.

## Usuarios y contexto

El usuario principal son los dueños de perros. El dispositivo está pensado para utilizarse principalmente dentro del hogar, en espacios donde permanece la mascota y donde la temperatura puede variar.
