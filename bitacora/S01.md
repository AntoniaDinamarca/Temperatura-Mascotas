## Objetivo de la sesión

Realizar una primera interpretación del desafío a desarrollar.

### Lo que sabemos

- La temperatura ambiental del hogar puede variar dependiendo del espacio y las condiciones del ambiente.
- La temperatura es una variable que podemos medir mediante un sensor.
- Los dueños de mascotas pueden tomar distintas acciones dependiendo de las condiciones del ambiente, como abrigar a su mascota o cambiarla de lugar.
- Queremos hacer visible la temperatura del ambiente para facilitar el cuidado de las mascotas.
  

### Lo que todavía no sabemos

- ¿Qué temperaturas son adecuadas para las distintas mascotas?
- ¿Cómo varía la necesidad de temperatura según las características de cada mascota?
- ¿Qué tipo de alerta sería más fácil de interpretar para el dueño?
- ¿Dónde debería ubicarse el dispositivo para obtener una medición útil?

### Supuestos que debemos comprobar

- Los dueños no siempre pueden identificar si la temperatura del ambiente es adecuada para su mascota.
- Conocer la temperatura ambiental podría ayudar al dueño a tomar mejores decisiones de cuidado.
- Una alerta visual podría ser una forma sencilla de comunicar cuándo la temperatura es muy alta o baja.

## Fenómeno
La temperatura ambiental puede influir en el bienestar y comodidad de las mascotas, pero no siempre es fácil para los dueños interpretar si las condiciones del ambiente son adecuadas para ellas.

## Contexto/Usuario
El problema ocurre principalmente en el hogar, donde las mascotas pasan gran parte del tiempo. Afecta principalmente a los dueños, quienes deben tomar decisiones relacionadas con el cuidado de sus mascotas según las condiciones del ambiente.

## Reflexión breve

**¿Qué fue fácil?**  
Fue fácil identificar el contexto y la variable que queríamos observar, ya que la temperatura ambiental se puede medir y el problema ocurre en un espacio cotidiano como el hogar.

**¿Qué fue difícil o generó desacuerdo?**  
Lo más difícil fue elegir el tema, porque teníamos varias ideas y no sabíamos cuál sería la mejor para desarrollar como dispositivo Low Tech.

**¿Qué necesitamos resolver para la próxima entrega?**  
Necesitamos investigar sobre las temperaturas adecuadas para las mascotas y definir cómo el dispositivo podría comunicar esta información de manera clara y sencilla.
